# **App Name**: Gorgia Online

## Core Features:

- Product Catalog: Browse products by category and view detailed information, including images and descriptions.
- Product Search: Search for specific products using keywords.
- Shopping Cart: Add products to a shopping cart and proceed to checkout.
- User Accounts: Allow users to create accounts to save their preferences and order history.
- Admin Panel: Manage products, categories, and user accounts from a secure admin panel.
- Order Management: Track orders and manage inventory.

## Style Guidelines:

- Primary color: Blue (#29ABE2) for trustworthiness and reliability.
- Background color: Light blue (#E0F7FA) to create a clean and airy feel.
- Accent color: Orange (#FFA000) for highlighting calls to action.
- Body and headline font: 'PT Sans', a humanist sans-serif combining a modern look and some warmth or personality.
- Grid-based layout to display products in an organized and visually appealing manner.
- Simple and recognizable icons for categories and UI elements.
- Subtle animations on product hover and during transitions to enhance user experience.
